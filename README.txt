RC MONITORING — PHONE INSTALL PACKAGE
=====================================
Files (all in ONE folder, no subfolders): index.html, sw.js, manifest.json, icon-192.png, icon-512.png, apple-touch-icon.png

1) Put the folder on any HTTPS website (phones only allow install over https).
   Easy free options: GitHub Pages, Netlify Drop (drag the folder), Cloudflare Pages.
   If you already host the old RC Monitoring app, just replace its files with these.

2) On the phone, open the https link:
   ANDROID (Chrome): menu ⋮ > "Install app" / "Add to Home screen".
   iPHONE (Safari):  Share button > "Add to Home Screen" > Add.

3) Open it from the new home-screen icon and log in once. The chatbot signs in automatically.
4) Tap the 🔔 button (above the chatbot button) and allow notifications to receive RC date alerts.
   The CVC Assistant chatbot signs in automatically with the same login.

Updating later: replace index.html on the host, then open the app twice while online.
